# Ember Visual Direction
## Purpose
This document defines the **visual identity and interaction style** for Ember.
Ember should feel:
* delightful
* playful
* emotionally engaging
* calm and focused
* modern and sleek
The goal is to create a productivity tool that feels **alive and rewarding**, not rigid or corporate.
Users should feel like they are **training a living creature**, not managing a task list.

# Core Visual Philosophy
Ember blends two design styles:
### Playful Creature World
Inspired by:
* cozy games
* creature companions
* fantasy worlds
Dragons should feel:
* expressive
* alive
* emotionally responsive

### Calm Focus Workspace
Inspired by:
* modern productivity tools
* minimal dashboards
* distraction-free environments
The UI must remain:
* uncluttered
* calm
* easy to read

# Emotional Tone
The interface should evoke:
* curiosity
* warmth
* gentle responsibility
* momentum
The user should feel:
> “My dragon needs training.”
Not:
> “I have a list of tasks.”

# Dragon Personality Direction
Each dragon type should have a subtle personality.
### Cinder
Energy: intense and fiery
Visual tone:
* warm lighting
* glowing embers
* sparks when training
### Moss
Energy: calm and grounded
Visual tone:
* nature tones
* soft green glow
* gentle breathing animations
### Drift
Energy: airy and curious
Visual tone:
* light motion
* floating particles
* soft ambient movement
# UI Style Principles
The interface should follow these rules:
### 1. Clean Layouts
Avoid crowded interfaces.
Focus on:
* one primary action
* minimal distractions

### 2. Soft Visual Depth
Use:
* subtle shadows
* glassy panels
* gentle gradients
Avoid:
* harsh outlines
* heavy borders

### 3. Large Friendly Elements
Buttons and interactions should feel:
* welcoming
* tactile
* easy to click

# Color Direction
The UI should use **soft, calming base colors** with **dragon-specific accents**.
Example palette:
Base UI:
background: deep charcoal
panels: soft slate
text: warm white
Dragon accents:
cinder → ember orange
moss → forest green
drift → sky blue
Accents should appear in:
* glow effects
* highlights
* small UI animations

# Typography
Typography should feel modern but friendly.
Recommended style:
Primary font:
clean sans-serif
Examples:
* Inter
* Manrope
* Geist
Guidelines:
* readable at small sizes
* generous spacing
* avoid decorative fonts

# Microinteractions
Microinteractions are essential to Ember’s emotional design.
Small animations should appear when:
* starting a focus session
* completing a session
* evolving a dragon
* interacting with tasks
These interactions reinforce **progress and momentum**.

# Dragon Animations
Dragons should not remain static.
They should have subtle idle animations.
Examples:
### Idle
* breathing animation
* tail movement
* soft glow pulses

### Session Start
When a focus session begins:
* dragon becomes alert
* small energy glow appears
* subtle particle effect
### Session Completion
After a session:
* dragon stretches or flaps wings
* glow briefly intensifies

### Evolution
When a dragon evolves:
* brief glow burst
* smooth transition to new stage
* subtle sound or visual pulse
This moment should feel **rewarding but not overwhelming**.
# Motion Design
Animations should be:
* smooth
* soft
* slightly playful
Avoid:
* abrupt transitions
* flashy motion
* distracting effects
Recommended animation timing:
150–250ms for UI transitions
400–600ms for dragon animations

# Resume Card Visual Focus
The **Resume Card** is the most important UI element.
When opening a project, the user's attention should go here first.
Example structure:
🐉 Your dragon remembers…
Last session:
Designed homepage wireframe
Suggested next step:
Refine navigation layout
[ Start 20-minute training ]

Design rules:
* strong visual hierarchy
* dragon image nearby
* clear action button

# Focus Session Screen
The focus session screen should feel calm and immersive.
Elements:
dragon
timer
current tasks
Avoid:
* notifications
* analytics
* clutter
This screen should feel like **a quiet training moment**.

# Icon System
Icons are stored in:
assets/icons
Icons should be:
* simple
* consistent stroke weight
* minimal detail
Icons should support:
* play
* pause
* timer
* tasks
* navigation

# Animation Philosophy
Animations should reward **progress**, not distract from work.
Good animations:
* dragon reacting to training
* glow when completing tasks
* smooth state transitions
Avoid:
* flashy game effects
* loud visual feedback
The feeling should be **calm magic**, not arcade energy.
# Long-Term Visual Goal
The ultimate visual goal of Ember is:
A productivity tool that feels like a **living creature companion**.
Users should gradually develop attachment to their dragons.
The interface should reinforce the feeling that:
“Progress strengthens the dragon.”
